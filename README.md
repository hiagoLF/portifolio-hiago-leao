# Hiago Leao's portfolio

Next.js project with TypeScript, CSS Modules, and SVGR. Includes the portfolio home and placeholder
project and experience routes.

## Development

- `npm install`: install dependencies.
- `npm run dev`: start the development server.
- `npm run lint`: check ESLint, formatting, and line lengths.
- `npm run format`: format supported files.
- `npm run build`: create a production build.
- `npm start`: run the production server.

Read [AGENTS.md](AGENTS.md) and [architecture](docs/architecture.md) before making changes.
